## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 先把 7 項集中到單一主計畫 | 避免每次回頭比對多份歷史檔 |
| 舊主計畫只保留封存與來源 | 降低誤判主線的機率 |
| 主計畫三檔對齊 planning-with-files 模板段落 | 降低後續溝通與驗收歧義 |
| 先回退 Flow Chart 圖形化改造到 MVP 版 | 先確保主線穩定，再切換到 Graph Toolkit 重新實作 |
| 移除舊 IMGUI Flow Chart，只保留 Graph Toolkit | 避免專案同時存在兩套編輯器造成維護與驗收混亂 |
| 工具入口統一到 `Tools/OpsidanosInk`，不保留舊路徑 | 避免入口分散與雙入口混淆，降低日常操作成本 |
| 提交前先清理臨時資產並驗證差異範圍 | 確保最終 commit 只包含入口路徑調整兩檔 |
| 匯出 MVP 以單一 commit 收斂 | 讓後續工項可以從乾淨工作樹直接接續 |
