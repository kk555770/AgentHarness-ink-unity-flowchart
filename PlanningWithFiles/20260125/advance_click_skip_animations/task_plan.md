# 任務計畫：點擊推進（快速連點）與動畫強制結束

## 目標
- 解決「動畫還沒結束時快速連點」造成的錯誤/狀態錯亂。
- 點擊行為改成兩段式：
  1. 當句打字機或人物動畫未完成 → 點一下就把它們「強制刷新到終點」
  2. 當句全部完成 → 再點一下才進入下一句（並開始下一句的打字機/動畫）
- 進入下一句前，會先把上一句殘留的動畫全部強制完成，避免疊加造成錯亂。

## Decisions Made
| 決策 | 原因 |
|------|------|
| 點擊採兩段式 | 直覺、常見 VN 操作，不會讓「推進」與「跳過演出」互相打架 |
| 測試只跑指定集合 | 避免跑到其他套件測試，產生多餘檔案、Unity 亂閃、增加排錯成本 |
