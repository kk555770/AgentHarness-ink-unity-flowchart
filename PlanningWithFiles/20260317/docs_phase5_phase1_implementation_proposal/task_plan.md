## 已做決策
| 決策 | 原因 |
|------|------|
| 先產出逐批次提案，再開始真正實作 | 先把依賴與驗證 gate 寫清楚，避免開工後邊做邊猜 |
| 批次提案直接引用現有測試護欄 | 讓提案能對到 repo 現況，而不是抽象任務清單 |
