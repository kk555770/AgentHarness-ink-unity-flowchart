# 核心信念

> 文件負責人：harness
> 最後更新：2026/03/25

## 這份文件在做什麼

這是 repo 的 golden principles 正式入口。

它只記最該被機械化、最常被 agent 反覆碰到的原則。

## 核心原則

- 真相留在 repo 裡，能被版本化與機械檢查
- 先做控制面，再補前端殼
- 入口要小，索引要穩，深層文件再慢慢展開
- 規則要寫進文件，也要寫進 guard，不能只靠口頭共識
- 不能把 projection、sidecar、runtime 狀態誤認成真相本體

## 文件治理

- 文件所有權與更新責任見 `Documentation/DocsOwnership.md`
- owner 分類只用固定 7 類，不要自己發明新類別
- 如果一條規則沒辦法被指出來、被索引到、被追蹤更新，就還不算正式落地
